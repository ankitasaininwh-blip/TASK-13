# TASK-13
JavaScript - Even or Odd Checker

Project Description

This project is a simple JavaScript program that checks whether a given number is Even or Odd.

How It Works

1. Enter a number in the input box.
2. Click on the Check Number button.
3. JavaScript checks the number using the "if-else" statement.
4. If the number is divisible by 2, it is Even.
5. Otherwise, it is Odd.
6. The result is displayed on the webpage and in the browser console.

Example Output

Input:

5

Output:

The number 5 is odd.

Input:

10

Output:

The number 10 is even.

How to Run

1. Open the project folder.
2. Open "index.html" in a web browser.
3. Enter a number.
4. Click Check Number.
5. View the result on the webpage.
6. Open the browser Console to see the "console.log()" output.
